# Chatbot Persona Deliverables

This repository contains three comprehensive deliverables showcasing custom chatbot persona engineering for real-world use cases. The project demonstrates prompt design, conversational flow structuring, and tone/memory control in three distinct AI bots:

- **Mental Health Companion (Miya):**
  - Empathetic, supportive, motivational chatbot for emotional wellness.
  - Provides calming advice, breathing exercises, and non-judgmental support.

- **Subject Tutor (Math Tutor):**
  - Patient, knowledge-based educational bot for guiding students through math topics.
  - Offers explanations, problem walkthroughs, positive reinforcement, and answer checking.

- **Travel Advisor:**
  - Enthusiastic, detail-oriented chatbot for trip planning and travel tips.
  - Recommends destinations, shares packing and safety advice, and builds custom itineraries.

## Contents

- **persona_profiles.md:**  
  Detailed persona profiles for each chatbot, including character traits, goals, behaviors, and prompt instructions.
- **sample_qa_flows.md:**  
  5+ sample Q&A exchanges for every persona, formatted for use in documentation or chatbot builders.
- **prompt_strategy_and_tone_control.md:**  
  Explanation of the prompt engineering behind each chatbot, with strategies for tone management and conversation flow.

## Usage

Each file is ready for academic, portfolio, or industry submission. You can also adapt these personas and scripts for rapid deployment using no-code platforms like Landbot, Chatbot.com, or Tidio.
